# Texture sources

- [Plywood](https://polyhaven.com/a/plywood), by Rob Tuytel, Poly Haven, CC0: 1K diffuse, OpenGL normal, and roughness maps. Downloaded via the Poly Haven API; MD5 values were verified.
- [Concrete Floor](https://polyhaven.com/a/concrete_floor), Poly Haven, CC0: 1K diffuse, OpenGL normal, and packed ambient-occlusion/roughness/metallic maps, copied from the reference Blender/Bevy project's credited assets. The material uses diffuse, roughness, and normal.

`sources.json` records the exact file URLs and MD5 checksums. Maps are packed into both the `.blend` and the GLB. Color maps use sRGB; normal/roughness data is linear. `impact.png` is an original procedural chipped-plywood decal, generated by `../../scripts/make_effect_assets.py`.
